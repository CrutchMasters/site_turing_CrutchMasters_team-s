**CodeFuture** — комплексная экосистема для организации IT-турниров и хакатонов. Объединяем организаторов, участников и экспертное жюри на одной платформе — от идеи до финального leaderboard.

---

## ✨ Возможности

### 🏆 Организация турниров
- Гибкая настройка дат, окна регистрации и формата (один или несколько раундов)
- Автогенерация публичной страницы турнира с описанием, правилами и статусом (`Draft` / `Registration` / `Running` / `Finished`)

### 👥 Командный центр
- Валидация заявок: уникальность участников, мин/макс состав команды
- Личный профиль: история участий, активные задания и статусы сабмитов

### 📝 Подача решений (Submissions)
- Таймер дедлайна и чек-лист must-have требований прямо в интерфейсе
- Единый стандарт: ссылки на GitHub, видео-демо и описание функционала

### ⚖️ Система оценки и жюри
- Рандомное распределение работ между членами жюри — никакой предвзятости
- Критериальное оценивание: Техническая часть, Функциональность, UX/UI
- Динамический leaderboard с разбивкой баллов по категориям

### 🚀 Дополнительно
- **Уведомления** — email и внутренние пуши о старте этапов и дедлайнах
- **Экспорт** — выгрузка результатов в CSV или Google Sheets в один клик
- **Сертификаты** — автоматическая генерация именных PDF-дипломов для победителей и участников

## 🛠 Быстрый старт

### 🖥 Фронтенд

```bash
sudo apt install npm
cd site_turing_CrutchMasters_team-s/frontend/
npm install
npm run dev
```

### ⚙️ Бэкенд

```bash
sudo apt install python3-venv
cd site_turing_CrutchMasters_team-s/backend/
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```
